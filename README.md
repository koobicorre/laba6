
# Лабораторная работа №6

Тема: Автоматизация администрирования Linux-сервера с помощью Bash

Выполнила: Вавилова Кристина Дмитриевна

Вариант: 6

## Цель работы

Изучить основные команды администрирования Linux и
автоматизировать проверку сервера, создание пользователей,
анализ журналов безопасности и запуск задач по расписанию.

## Содержание проекта

- health_check.sh — проверка состояния Linux-сервера
- create_users.sh — создание пользователей из CSV
- employees.csv — список сотрудников
- log_analyze.sh — анализ журнала безопасности
- auth_sample.log — учебный журнал авторизации
- crontab.txt — расписание автоматической проверки

## Особенности варианта 6

Проверяемые службы: cron, nginx

Порог CPU: 80%
Порог RAM: 80%
Порог DISK: 80%

Подозрительные IP: 2 и более неудачных попыток входа

Расписание: по будням в 08:30

## Запуск программ

Проверка состояния сервера:

chmod +x health_check.sh
./health_check.sh

Создание пользователей:

chmod +x create_users.sh
sudo ./create_users.sh employees.csv

Анализ журнала:

chmod +x log_analyze.sh
./log_analyze.sh auth_sample.log

Проверка расписания:

crontab -l

## Пример результата

cron: active
nginx: active

При превышении порогов скрипт выводит предупреждение.

Скрипт анализа журнала определяет неудачные входы,
подозрительные IP-адреса и попытки sudo без прав.

## Вывод

В ходе лабораторной работы были изучены основные
возможности автоматизации администрирования Linux.
Bash позволяет объединять команды в скрипты,
сокращать количество ручных действий и выполнять
регулярные проверки сервера.
